# BankingOperations - Система анализа банковских операций

Описание проекта
Проект BankingOperations представляет собой систему для анализа банковских транзакций, предоставляющую следующие возможности:

1) Генерация отчетов по операциям
2) Поиск транзакций по различным критериям
3) Анализ расходов по категориям
4) Отображение курсов валют и цен акций
5) Расчет статистики по картам

# Основные модули
1) views.py
Главный модуль для генерации комплексного отчета, включающего:
- Приветствие в зависимости от времени суток
- Статистику по картам (расходы, кешбэк)
- транзакций
- Курсы валют
- Цены акций

2) utils.py
Вспомогательные функции:
- get_greeting() - возвращает приветствие по времени
- load_user_settings() - загружает настройки пользователя
- load_transactions() - загружает транзакции из Excel
- filter_transactions_by_date() - фильтрует транзакции по дате
- calculate_card_stats() - рассчитывает статистику по картам
- get_top_transactions() - возвращает топ-N транзакций
- fetch_currency_rates() - получает курсы валют с ЦБ РФ
- fetch_stock_prices() - получает цены акций через Alpha Vantage API

3) services.py
Сервисы для работы с транзакциями:
- load_transactions() - загрузка данных
- simple_search() - поиск транзакций по описанию или категории

3) reports.py
Генерация отчетов:
- load_settings() - загрузка настроек
- load_transactions() - загрузка транзакций
- spending_by_category() - отчет по расходам категории за 3 месяца

# Использование
CLI интерфейс (main.py)
bash
Copy
- Генерация отчета на определенную дату
python main.py отчет "2023-11-15 14:30:00"
- Поиск транзакций
python main.py поиск "АЗС"
- Отчет по категории
python main.py категория "Супермаркеты"
python main.py категория "Рестораны" "2023-11-01"
Настройки пользователя

Файл user_settings.json должен содержать:
json
Copy
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "MSFT"],
  "alpha_vantage_api_key": "your_api_key"
}
Требования
Python 3.8+

# Тестирование
Тесты расположены в папке tests/ и используют:

- Параметризацию тестов
- Mock для тестирования API
- Patch для изоляции тестов

Запуск тестов:

bash
Copy
python -m pytest tests/
Логирование
Приложение ведет логи в файл app.log с информацией о:
- Загрузке данных
- Ошибках
- Выполнении операций
